# The class is the country

The model predicts the country a coffee was grown in, and coffees from one country form one class. Raw class folders keep their names, `dataset/classes.txt` maps each folder to its country, and the country name is the class key. Farm region and misc are facts about a photo, never labels (`GLOSSARY.md`).

Source: [ML-3](../ticket_country_classes.html) D1, D2.
