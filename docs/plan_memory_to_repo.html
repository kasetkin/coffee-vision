1. Phase order and why

ADRs first: the standards, out-of-scope files and runbooks link to them. CLAUDE.md comes after the files it points at exist. Memory is slimmed only once everything it holds has a home, and the probe runs last, against the slimmed memory, because that is the setup every later session has.
