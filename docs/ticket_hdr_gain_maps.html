Owner request, 2026-11-03. While grilling ML-19, on its D20 (the main image only, or the gain map applied): "answer (a) for today, but create a stub ticket for applying HDR maps to the photos during canonicalization."

1. Summary

Stub. The question is whether rendering a photo through its gain map, then mapping it into the canonical photo's range, gives either model a better input than the main image, and at what cost on the front. Nothing is proposed yet.

2. Background

Measured 2026-11-03 (analysis/ml19/); to be checked when the ticket is written.

  • How many. 1,518 of the 2,463 photos in dataset/ hold a second image (an MPF image, an HDR gain map or a HEIF auxiliary image); not yet split into gain maps, depth maps and previews.
  • Today. Both models read the main image only (load_rgb_image), and ML-19 D20 keeps it so. A canonical photo is Rec.2020, decoded to 8-bit sRGB for the models (ML-19 D2, D7): an HDR rendering has to be tone-mapped into that range.
  • Parity. Applying gain maps changes the input for every photo that has one, in training and serving: a re-canonicalization and a retrain, measured as any input change is (ADR 0002).
