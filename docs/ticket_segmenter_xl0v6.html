  • Training state today. seg_finetune.train holds the best epoch's decoder in memory and writes models/seg/<name>.pt once, at the end. fit_frozen_head has no epochs: it embeds every patch and its 8 augmented views (about 2.3 h of the views alone per seed), then makes one convex fit at the fixed C, all in memory (ADR 0025). A reboot loses all of either: ML-9's XL0-v4 restarted once, and ML-12's first classifier run died about 7 h in.
  • The classifier. exp276–278 (frozen DINOv3 ViT-B/16, cls_mean, C = 0.1, 8 augmented views per patch): val 0.9614–0.9718, test 0.9694–0.9813 patch macro-F1, on a pool of 1,376 photos; exp276 is seed 42, val 0.9718, test 0.9813. The next run is exp279.

5. Risks

IDRiskEvidence and mitigation
R1The new photos carry GPS. The dry run above: all 44. They are gitignored and outside DVC today, so nothing has left the machine. The strip runs first, with rows in labels/ml3/strip_manifest.csv, and a second dry run must find them clean before dvc add and any push.
R2The owner's time. pass7 showed 273 positives; pass8 shows about 354 (D2), each with up to seven rounds, then about 117 test positives judged blind. The session is resumable, and pass7's accepted labels start as round 1, so a good one costs one key.
R3Painted labels are new to a fine-tune. A painted edge is a disc's, not a model's; nothing has trained on one yet. The blind comparison against XL0-v5 on the test split, whose masks no brush touched, measures what XL0-v6 learned; the point probe already skips painted labels (ML-11).
R4One seed each departs from ADR 0002. ADR 0002 asks for seeds 42, 123 and 7, paired: seed spread here is larger than the effects measured, and single-seed wins have reversed. The fine-tune's score swung 0.635–0.973 between epochs and seeds (ML-12 R2). The ADR also has the work print the paired results and stop for the owner to decide; D6 departs from that too, as ML-12 D6 did, with Claude shipping. The owner's decisions for this ticket (D3, D6), not a change to the ADR. Mitigation: each run is paired with its predecessor at the same seed (XL0-v6 with xl0_v5 at 123, exp279 with exp276 at 42), so the labels and the crops are each the one difference; the segmenter is adopted on the owner's blind judgement, not its score; the classifier ships only above a line drawn before the run (D10); the report says it is one seed.
R5The blind comparison is on a grown test split. About 117 test positives, not ML-12's 91 (95 since 2026-10-26). XL0-v5 is predicted on the same photos in XL0-v6's new predict stage, so the pair is like for like; the numbers are not comparable with ML-12's.
R6The classifier trains on crops the owner has not seen. D5. Gained and lost coverage reported per photo, sheets for the owner's later review, as in ML-12 R3.
R7A resumed run could differ from an uninterrupted one. A resume that restored the weights but not the optimizer, the schedule or a random stream would train a different model with nothing to show it. The resume state holds all of them and a fingerprint of the run's inputs; a run whose fingerprint differs never resumes from it: the leftovers are deleted, logged, and the run starts fresh (D8). A toy run interrupted and resumed must give the same checkpoint, byte for byte, as one run straight through (plan P2, P3).
